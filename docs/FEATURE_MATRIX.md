# Erii 2.1.1 功能矩阵

更新于 2026-10-30。保留原 36 项计划编号，纠正“后端已有却标未开始”和旧测试数字混用的问题。此表描述代码所在层，不声称 iOS 真机验收通过。后端 279 项回归；本版前端未执行 Xcode/XCTest。

本轮先完成精简与性能，不要求把全部接口变成主屏入口。具体当前变更见 RELEASE_2.1.1.md。

| 编号 | 需求 | 当前代码状态 | 下一步 |
|---|---|---|---|
| 01 | 精简导航（聊天/小本子/我） | 前端已有，待本版构建 | RootView / NotebookView / MeView；验证三入口与返回栈 |
| 02 | 原生液态玻璃 | 移除全局 Tab 材质覆盖，待真机 | 用 iOS 27.2 SDK 观察系统导航材质与降级，不能以 blur 冒充适配完成 |
| 03 | 壁纸适配（裁切/缩放/遮罩/亮度预览） | 前端已有，本版修像素倍率 | 后台下采样、旋转/键盘、壁纸模糊能耗 |
| 04 | 微信式消息操作（左滑引用/双击放大/多选转存） | 已有部分消息操作 | 保留引用/复制/删除/放大；左滑与多选闭环仍待完善 |
| 05 | 阅读位置（不被新消息拉底） | 本版修改底部观测与未读计数 | 快速滚动、新消息、删除、键盘与图片高度变化回归 |
| 06 | 整套主题（樱花白/东京夜雨/深海蓝） | 主题源码保留 | 动态字体、对比度、提示音资源与真机一致性 |
| 07 | 连续消息理解 | 已有内存队列，可靠性待加强 | 杀进程恢复、媒体连发、持久化与幂等 |
| 08 | 自然分条回复 | 后端分段逻辑已有 | 核对 segments.py / 返回协议与前端稳定 ID、显示节奏 |
| 09 | 风格调节（长度/提问/表情/动作/称呼） | 前后端源码已有 | StyleSettingsView / style.py；本版构建与真实对话待验 |

| 13 | 绘梨衣设定卡 | 设定卡接口与基础主页已有 | 原著章节证据仍需整理；找到目录不等于提取了人物证据 |
| 14 | 人物演绎模式（原著/平行日常/桌宠） | 后端模式接口已有 | canon / parallel / pet；iOS 控件、剧透范围与上下文衔接 |
| 15 | 小本子表达（手写便签） | 便签接口已有 | iOS 手写样式、收藏与频率闭环待接 |
| 16 | 连续虚构日常 | world / companion 日常代码已有 | 虚构标记、连续性、日程变更展示 |
| 17 | 熟悉程度变化 | 熟悉度接口已有 | 暂停/重置和前端可解释反馈；不制造情感压力 |
