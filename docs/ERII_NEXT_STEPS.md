## 你需要提供的外部条件（我做不到的）

| 想实现什么 | 需要你提供 |
|---|---|
| 用 5G 流量稳定连接（正式公网） | 一台云服务器 + 一个域名（或先用 Cloudflare 临时隧道，地址会变） |
| 实时语音/视频通话真正接通 | LiveKit Server（URL+Key+Secret）+ STT 服务 + TTS 服务 |
| 图片真正被"看懂" | 一个视觉模型（DeepSeek 无视觉，需 OpenAI 兼容的 vision 模型 + key） |
| 视频通话的角色口型/表情 | 分层立绘素材（眼睛/嘴巴/表情独立图层） |

> 当前公网用的是 Cloudflare 临时隧道，电脑重启地址会变。固定下来需要注册免费域名（us.kg）或 7 元买 .xyz。
