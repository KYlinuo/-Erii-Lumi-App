# Project LUMI — 产品需求文档（PRD）v0.1

> 状态：v0.1 已实现 · 更新时间：2026-10-26

## 1. 一句话定位

LUMI 是一个有独立形象与名字的 AI 少女陪伴应用：原生 iOS 客户端 + 自托管后端，
所有回复都来自真实大模型，聊天记录本地与服务端双份持久化。

## 2. 目标用户

希望拥有一个「稳定、私密、有温度」的 AI 陪伴对象的个人用户。

## 3. v0.1 范围（Must Have）

| # | 需求 | 验收标准 | 状态 |
|---|------|---------|------|
| 1 | 原生 App 启动界面 | SwiftUI 启动页展示形象与名称，探测服务器后进入聊天 | ✅ |
| 2 | 独立 AI 少女头像及名称 | LUMI 命名；头像为独立绘制的矢量形象 + App Icon | ✅ |
| 3 | iOS 原生聊天 UI | SwiftUI + NavigationStack，气泡、输入条、打字指示 | ✅ |
| 4 | 发送文字消息 | ComposerBar，空消息禁发，上限 8000 字符 | ✅ |
| 5 | 后端调用真实模型 | FastAPI → OpenAI 兼容适配器 → DeepSeek；未配置 Key 时明确报错 | ✅ |
| 6 | 消息保存到 SQLite | 用户消息先落库；失败也不丢历史 | ✅ |
| 7 | 重启恢复历史 | 本地快照 + 服务端会话恢复，测试覆盖 | ✅ |
| 8 | 失败/断网/超时提示 | 7 类错误码分别映射不同中文提示，可重试 | ✅ |
| 9 | 设置页连接状态 | 实时探测 /health，展示版本/模型/数据库/认证状态 | ✅ |
| 10 | 真实 API 端点 | 无任何假回复/演示数据逻辑；单测证明未配置即 503 | ✅ |

## 4. 非功能需求

- **安全**：模型 API Key 只存后端；客户端令牌存 Keychain；`.env` 不入库；单用户认证 + 限流。
- **可维护**：Xcode 工程配置（project.yml）可在 Windows 维护；CI 在 macOS Runner 构建。
- **诚实**：任何环境下不得伪造「构建成功/测试通过/模型回复」。
