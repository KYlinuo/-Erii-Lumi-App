# 性能验收记录

主验收系统：iOS 27.2；设备型号与是否支持 ProMotion 需实际记录。记录实际系统 build、Xcode/SDK、Release commit、屏幕最大帧率、低电量/限制帧速率/热状态；这些均不能从聊天记忆自动填为已验证。

自定义工程目标（待真机测量，不是当前成绩）：

- 正常温度和正常电源设置下，高刷滚动支持系统选择到 120Hz；120Hz 时间预算约 8.33ms。
- 用 Instruments Animation Hitches / Core Animation / Time Profiler 检查长列表、图片首显、键盘和页面切换；按系统实际目标间隔判断错过帧，不能把合理的 80/60Hz 算作 App 失败。
- 先测至少三轮 60 秒快速滚动；目标滚动 hitch time ratio <5ms/s（工程目标），保留原始 trace 与复现数据。
- 本地输入至回显 P95 <50ms；已有本地聊天到首屏目标 <1s；网络生成耗时另记，不混作 UI 卡顿。
- 数据集：1000 与 10000 条文字、50 张混合尺寸图片、20 条音频；开关壁纸模糊、Dynamic Type、减少动态效果。
- 记录冷/热缓存峰值内存、返回页面后保留量和 10 次进出后的趋势；不能仅凭 NSCache 限额宣称全 App 有严格内存上限。
- 低电量、限制帧速率、后台恢复和温控降频下仍需响应正常，不通过高频唤醒抵抗系统节能。

输出表列：场景、设备/系统、SDK、数据量、电源/热状态、目标刷新率、实际帧时间/卡顿指标、峰值内存、输入延迟、trace 路径、结论、未完成原因。不能用模拟器结果替代真机。
