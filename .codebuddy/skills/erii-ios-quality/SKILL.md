# 绘梨衣质量与性能

以用户给定项目根目录为工作区。先读 `docs/RELEASE_2.1.1.md`、`docs/WORKBUDDY_5H_PROMPT.md`，再检查当前差异；文件不存在时自行发现最新 release，不凭文件名认定版本。

按需求只加载对应检查项。性能目标、设备状态和记录表见 [references/acceptance.md](references/acceptance.md)。

## 精简

1. 追踪候选代码的调用、导出、测试、路由注册、资源清单、反射字符串及兼容入口。搜索不到直接调用不等于无用。
2. 区分生成物/过期记录与运行代码。可移除旧 IPA、运行期 relay 队列、重复演示数据；保留用户真实 DB、资源、迁移、测试和有效 API。
3. 先证明等价再合并。尤其保留 `app.security._tokens_match` 的兼容导出；不要把实例方法、数据库副作用或注册导入当成无用赋值删除。
4. 记录删除路径、理由和恢复来源。不得靠删除失败测试提高通过率。

## 流畅度

1. 不在 SwiftUI body 做文件 IO、图片解码、JPEG 重编码、网络请求、全量排序或大数组复制。
2. 图片按显示尺寸在非主线程下采样，缓存有成本预算，同一请求复用任务。只更新需要资源的单行，不广播所有气泡。
3. 输入框草稿状态与历史列表隔离。消息使用稳定 ID。滚动只发布“是否接近底部”等低频状态，不逐像素刷新整个页面。
4. 原生 SwiftUI/UIKit 动画由系统管理。Info.plist 保留 ProMotion opt-in。禁止增加常驻 CADisplayLink/120Hz Timer/空动画来强迫高刷；如果确有自绘，按帧时间推进并在不可见时停用。
5. 动画尊重减少动态效果；后台停止循环；图片原图只在用户需要时读取。键盘、返回手势和系统导航由各页面唯一的 NavigationStack 管理。
6. 不声称全局锁定 120fps。记录低电量模式、限制帧速率、温度、设备、系统、SDK、构建配置后，测真实滚动与交互。

## 可靠性

- 持久化请求 ID 和会话 ID，重试不重复生成；上传、发送、失败、同步各有明确状态。
- 数据层变更先做 SQLite 一致备份，在副本测试迁移/恢复。不要复制活跃 db 后忽略 WAL。
- 测试普通消息与删除 tombstone、分页游标、临时会话隔离；保留现有回归断言。
- 模型默认使用桩测试；真实调用、签名或公网发布按用户已授权范围执行。

## 验证与交付

在根目录执行 `python scripts/audit_source.py`、`python -m ruff check backend/app --select F401,F841`、`python -m pytest -q` 和 `python scripts/swift_lint.py`。Mac 上用 `scripts/ios_validate.sh` 做构建和 XCTest；SDK/模拟器缺失就记录阻塞，不能把语法检查标成编译通过。

源码包排除 `.git`、虚拟环境、缓存、旧构建产物和临时测试库。用户指定的私人包可保留真实 DB；公开包必须排除私人数据。输出实际测试证据、残留限制、下阶段任务。无关功能先列清单，不擅自加入大型第三方框架。
